# Fork of the original react-native-track-player

This repository forks [doublesymmetry/react-native-track-player](https://github.com/doublesymmetry/react-native-track-player) and keeps a streamlined set of customisations for our projects.

For documentation, issues, and new features please refer to the upstream project; this fork primarily exists so we can ship internal tweaks on top of their latest release.
